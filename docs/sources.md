## How to use this file

- Cite in content as `[S12]` or via the `sources` field in a content file's frontmatter.
- **Every numeric claim needs a source.** No exceptions — see
  [content-strategy.md](content-strategy.md) §4.
- Update **Last verified** whenever you re-check, even if nothing changed.
- Mark **Volatility** so reviewers know what to prioritize: High (rates, rebates, program
  terms), Medium (law, standards), Low (physics, general technique).
